Build a complete, modern, production-ready full-stack job hunting platform called **HireLoop**.

## Project Overview

HireLoop connects job seekers and employers in one platform. It must support job discovery, applications, company profiles, recruiter tools, subscriptions, analytics, and admin management.

The system has 3 roles:

1. Seeker
2. Recruiter
3. Admin

## Recommended Tech Stack

* Frontend: React + Vite
* Styling: Tailwind CSS
* Routing: React Router
* Charts: Recharts
* Backend: Node.js + Express.js
* Database: MongoDB
* Authentication: JWT + secure password hashing
* Payments: Stripe
* File upload: Cloudinary or equivalent
* Email notifications: Nodemailer or equivalent
* API communication: Axios
* Icons: Lucide React

## Design Direction

Create a premium, modern SaaS-style UI inspired by Linear, Vercel, Stripe, and modern job platforms.

Use:

* Clean responsive layouts
* Dark/light mode
* Glassmorphism where appropriate
* Rounded cards
* Subtle shadows
* Smooth animations
* Professional typography
* Excellent spacing
* Responsive mobile/tablet/desktop layouts
* Accessible buttons, forms, tables, modals, and navigation

Avoid excessive animations or unnecessary visual effects.
